# Programación 1º DAM · Estudio interactivo

Web de estudio para la asignatura de Programación (Java) de 1º de DAM,
basada en los apuntes de la asignatura.

## Qué incluye
- Temas 1 y 2 con teoría, simuladores y ejercicios de código.
- Un editor con terminal que ejecuta un subconjunto de Java en el navegador.
- Ejercicios de predecir la salida y de corregir código.
- Relación de ejercicios del profe, con su corrección desplegable, para hacerlos en NetBeans.

## Archivos
- `index.html`: portada con los dos temas.
- `tema1.html`, `tema2.html`: cada tema, en un solo archivo.
- `vercel.json`: configuración para publicarla en Vercel.

## Importante
Es material de estudio no oficial, hecho por un alumno. El código se ejecuta con un intérprete propio, así que puede diferir en detalles de un Java real. Los ejercicios del profe se deben hacer en NetBeans.
