Fuera de los apuntes (opcional)

La teoría de esta web es la de los apuntes, tal cual. Estos cuatro puntos son matices míos sobre cómo se comporta Java en la práctica, por si quieres comentarlos en clase. Los marco con ⚠ en cada apartado. Para el examen, contesta lo que dicen los apuntes y el profesor.

  • Desbordamiento (overflow): los apuntes dicen que la JVM lanza un error. En realidad Java no avisa: el valor da la vuelta en silencio.
  • El símbolo ^ se usa como «potencia» en algunos ejemplos de precedencia, pero en Java es XOR. La potencia es Math.pow.
  • Math.round y Math.pow/sqrt: la tabla dice «entero» y «real o entero», pero en Java Math.pow y Math.sqrt siempre devuelven double (8.0) y Math.round(double) devuelve long.
  • La tabla del short marca «sin signo» un rango que es con signo.

En cristiano

Apartado 7 · Qué es Java

Practica y simula

Línea de versiones
  • 1991: Gosling crea Java en Sun Microsystems. 1996: primera versión.
  • JDK 1.0, 1.1 → Java 2 (J2SE 1.4, J2SE 5) → Java SE 6, 7…
  • 2010: Oracle se fusiona con Sun. Casi todo el código es GNU/GPL (software libre).
  • Java 8: programación funcional (lambdas, Stream API). Java 9 (2017): Project Jigsaw (módulos). Desde 2018: versión nueva cada 6 meses.
  • Antes de Java 11 JRE y JDK se distribuían por separado; desde Java 11 todo va en el JDK.
  • Los applets se eliminaron en Java 26 por problemas de compatibilidad y seguridad.

⚠ Fuera de los apuntes: dos detalles

1) En los ejemplos de prioridad, «3 + 2 * (18 - 4 ^ 2)» usa ^ como potencia, pero en Java ^ es XOR. Para elevar se usa Math.pow. Pruébalo en la calculadora con 2 ^ 3 y con Math.pow(2, 3).

2) Math.pow y Math.sqrt devuelven siempre double (Math.sqrt(64) sale 8.0) y Math.round(5.7) devuelve un long (6).
